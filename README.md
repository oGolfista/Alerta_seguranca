# Alerta Segura

Projeto Final de IHC — UniCesumar Campus Ponta Grossa, 2025/1

---

## O que é esse projeto?

O **Alerta Segura** é um protótipo de aplicativo de segurança para mulheres. A ideia é simples: apertar um botão em situações de perigo para avisar contatos de confiança com a sua localização em tempo real, sem precisar digitar nada.

O projeto foi feito como trabalho final da disciplina de Interface Humano-Computador, aplicando os conceitos que vimos ao longo do semestre: persona, prototipação, testes de usabilidade e acessibilidade.

---

## O problema

A violência contra a mulher é um problema sério no Brasil — segundo o Anuário Brasileiro de Segurança Pública de 2023, uma mulher é vítima de algum tipo de violência a cada 6 minutos. Em situações de risco, ligar ou mandar mensagem pode ser impossível. O app foi pensado pra resolver exatamente isso.

---

## O que o app tem

- Botão de pânico que ativa segurando por 3 segundos (evita acionar sem querer)
- Alerta automático enviado para os contatos cadastrados, com localização
- Mapa com áreas de risco relatadas por outras usuárias
- Histórico de alertas
- Interface simples — dá pra usar com uma mão só

## Como testar o protótipo

Baixa o repositório, abre a pasta `prototype` e clica com o botão direito no arquivo `index.html` → Abrir com → Google Chrome.

Na tela que abrir, clica em **Entrar**. Pra disparar o alerta, segura o botão vermelho por 3 segundos. Dá pra explorar o resto pelo menu lá embaixo — tem Contatos, Mapa e Configurações.
